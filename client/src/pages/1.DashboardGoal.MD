Tienes varias opciones mejores que emojis para mejorar la apariencia:

## Opción 1: Usar Lucide Icons (recomendado)

Ya tienes Lucide instalado en tu proyecto, úsalo:

```typescriptreact
import { Flame, Scale, Dumbbell } from "lucide-react";

// Definir fuera del componente
const goalIcons = {
  lose: <Flame className="size-5 text-orange-400" />,
  maintain: <Scale className="size-5 text-blue-400" />,
  gain: <Dumbbell className="size-5 text-emerald-400" />
};

const goalLabels = {
  lose: "Lose Weight",
  maintain: "Maintain Weight",
  gain: "Gain Muscle"
};

// En tu JSX
<div className="flex items-center gap-2">
  {goalIcons[user.goal]}
  <p className="text-white font-semibold capitalize">
    {goalLabels[user.goal]}
  </p>
</div>
```

## Opción 2: Background con gradiente + icono

```typescriptreact
import { TrendingDown, Minus, TrendingUp } from "lucide-react";

const goalConfig = {
  lose: {
    icon: TrendingDown,
    label: "Lose Weight",
    gradient: "from-orange-500 to-red-500",
    iconColor: "text-orange-100"
  },
  maintain: {
    icon: Minus,
    label: "Maintain Weight", 
    gradient: "from-blue-500 to-cyan-500",
    iconColor: "text-blue-100"
  },
  gain: {
    icon: TrendingUp,
    label: "Gain Muscle",
    gradient: "from-emerald-500 to-green-600",
    iconColor: "text-emerald-100"
  }
};

const config = goalConfig[user.goal];
const Icon = config.icon;

// JSX
<div className={`flex items-center gap-2 px-4 py-2 rounded-lg bg-linear-to-r ${config.gradient}`}>
  <Icon className={`size-5 ${config.iconColor}`} />
  <p className="text-white font-semibold">
    {config.label}
  </p>
</div>
```

## Opción 3: Badge con icono (minimalista)

```typescriptreact
import { Target, Activity, Zap } from "lucide-react";

const goalData = {
  lose: { icon: Zap, label: "Lose Weight", color: "bg-orange-100 text-orange-700 dark:bg-orange-900/20 dark:text-orange-400" },
  maintain: { icon: Activity, label: "Maintain Weight", color: "bg-blue-100 text-blue-700 dark:bg-blue-900/20 dark:text-blue-400" },
  gain: { icon: Target, label: "Gain Muscle", color: "bg-emerald-100 text-emerald-700 dark:bg-emerald-900/20 dark:text-emerald-400" }
};

const goal = goalData[user.goal];
const GoalIcon = goal.icon;

// JSX
<div className={`inline-flex items-center gap-2 px-3 py-1.5 rounded-full ${goal.color}`}>
  <GoalIcon className="size-4" />
  <span className="text-sm font-semibold">
    {goal.label}
  </span>
</div>
```

## Opción 4: Solo mejorar los emojis existentes

Si quieres mantener emojis pero mejorarlos:

```typescriptreact
<div className="flex items-center gap-2">
  <span className="text-2xl leading-none">
    {user.goal === "lose" && "🔥"}
    {user.goal === "maintain" && "⚖️"}
    {user.goal === "gain" && "💪"}
  </span>
  <p className="text-white font-semibold capitalize">
    {user.goal === "lose" && "Lose Weight"}
    {user.goal === "maintain" && "Maintain Weight"}
    {user.goal === "gain" && "Gain Muscle"}
  </p>
</div>
```

## Mi recomendación

**Opción 1 o 3** son las mejores porque:
- ✅ Consistentes en todos los navegadores/sistemas
- ✅ Personalizables (color, tamaño)
- ✅ Se ven profesionales
- ✅ Funcionan bien en dark mode
- ✅ Ya tienes Lucide instalado
